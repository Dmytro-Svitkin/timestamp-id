# timestamp-id
`timestamp-id` is a small crate, that lets you generate id based on your system timestamp or the choosen time, `base62`-converted IDs are built-in.

## Installation

Add `timestamp-id` to your `Cargo.toml` dependencies:

```toml
[dependencies]
smath = "0.0.1"
```
